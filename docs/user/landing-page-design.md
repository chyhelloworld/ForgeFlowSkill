# FF 落地页专项参考

这是 ff-design 的按需分支，仍是21个技能，不另装 ai-design-skills。适合产品介绍、营销、报名/预约等 Persuade 页面。后台工作台、普通组件和文章阅读继续原流程；混合页面只处理选定的推广区域。

## 怎样使用

可以说：“用 ff-design 做产品介绍页，先按落地页专项整理受众、疑虑和真实证据，给我看章节纲要，确认后再实现。”已有资料和品牌直接复用，只追问会改变结构或承诺的未知。确认过的同版纲要不重复问；局部改字不重走流程。

输出依次为章节纲要（每节一句问题）及关键缺口 → 用户确认 → 文案与获准的逐节实现 → 同版内容、交互和响应式证据。设计方向仍按原 ff-design 处理，不因纲要确认就宣称真人选定视觉方案。

## 保留什么，不带入什么

借鉴 elayadesign/ai-design-skills 固定 4fdcdd52 的目标/受众、疑虑、证据与内容编排，集中命名样式和逐节迭代。保留各项目自己的品牌，不强制特定字体、色值、导航、社会证明或标语动效。真实客户/效果数据/价格/保证没有依据就不用，缺渠道的原型按钮不能伪造成功。

不包含 Impeccable engine/hooks/live，也不自动接入 oil-diff。未新增安装器/运行时或单技能版本；更新随 FF 全包及工作提交，原有 ff-diagram/ff-writing-document 独立版本机制不变。

## 怎么判断可用

看访客是否能理解实际能力、边界和下一步；说明能否回到真实资料；按目标桌面与约390px小屏验证阅读、操作、必要状态和局部改动回归。源码静态检查不能证明页面实际显示、转化率或用户认可。无浏览器、设备或真实后端时如实列未验证项。
