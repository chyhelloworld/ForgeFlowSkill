# 在 Codex `/goal` 中使用 ForgeFlow

0.9.2-goal.2 是隔离实验候选，提供五个现有技能的目标对账指引；未发布，原生 Goal 端到端结果以实际实验记录为准。它不会自动设置、暂停或完成目标，也不新增后台循环。

本候选已在实际宿主观察到选定项目技能加载、暂停后自动续读，以及审计 Goal 完成时合成产物仍被拒绝；预算仅继承旧的有限观察。未证明逐 token 硬截断、暂停后即时终止子进程、完整产品 E2E 或所有技能/宿主可靠执行。审计完成不等于产品已获真人接受；具体版本、失败和未测范围见[原生验证与证据继承](../../iterations/0.9.2-goal.2/native-closeout.md)。

## 使用步骤

1. 在目标项目打开 Codex，确认宿主实际提供 `/goal`，并核对选中 FF 技能的路径、版本及可用项目工具。旧项目的同名技能可能同时出现；仅写技能名不保证加载了候选。项目规格、唯一计划和产品证据留在目标项目。
2. 先用 `$ff-intake` 只读核对当前目标、规格、计划、工作区和权限。已有明确有效计划就引用它；缺目标/规格/计划才转相应职责，普通 FF 不要求 Goal。
3. 由用户在实际宿主中设置具体目标，保留现有范围和授权，例如：

   ```text
   /goal 按本项目已确认规格和唯一计划完成剩余获准切片，验证实际主流程。
   保留已有修改；不合并、不发布。完成条件包含同版行为证据与适用独立审查。
   尚缺约定真人验收时明确待接受；预算未知要说明，不另建任务库。
   ```

4. 显式请求 `$ff-intake` 对账本聊天原生目标与项目要求，再按缺口进入 `$ff-plan`、`$ff-implement`、`$ff-review`。每片复核授权、预算、依赖及旧动作结果；讨论中的新想法不自动入计划，明确采纳的变化只更新受影响部分。
5. 需要编辑、暂停、恢复或清除时，使用该宿主实际提供的原生控件/帮助。桌面目标界面与交互 CLI 的命令形式可能不同；不要将另一宿主参数直接套用，也不发明预算开关。用户暂停后不启动新动作，已启动操作另行对账。
6. 换上下文前按需 `$ff-handoff` 留获准短检查点；恢复先 `$ff-intake`，再按需用现有 resume 检查器。最后 `$ff-deliver` 给可访问结果、真实证据、未知/失败和接受状态，原生 complete 与 FF 真人接受分开。

## 支持边界

| 能力 | 本候选提供什么 |
| --- | --- |
| 当前聊天目标与项目要求映射 | 五个技能按需读取自带契约，复用现行规格、唯一计划和稳定动作 ID |
| 中途明确采纳、设计限定与原生编辑 | 按最新真实来源核对语义目标；既有授权持续有效，readiness 不代表新权限 |
| 中断与预算/故障 | 使用现有回执与只读检查；未知保持 unknown，失败原样保留，停止受影响新动作 |
| 原生目标读写、自动同步 | 本适配未实现；无公开可调用且获准的工具时由用户操作，不读私有 sessions/内部状态库 |
| 调度、跨聊天全局目标、exactly-once | 不提供；目标与技能不会扩大宿主沙箱、审批或发布权限 |
| 原生暂停、预算硬停、complete | 按实际观测记录；指令、协议形状、技能安装或模拟回答不能替代真实宿主实验 |
| FF 最终完成 | 技术证据、独立审查、真实用户接受分别报告；缺约定接受仍待接受，明确拒绝则保留拒绝及版本/来源，不被 native complete 覆盖 |

原生预算不可见写 unknown，不当无限或 0；无法证明在明确硬预算内时停止依赖该预算的新动作。工具内部失败即使外层 CLI exit 0 仍是失败。只改原生状态/统计不自动改变 FF 语义 `goalRevision`。

恢复检查器使用当前核实目标，而非旧 checkpoint 的值。例如从实际安装项目根运行：

```powershell
python -X utf8 .agents/skills/ff-handoff/scripts/resume.py checkpoint.json --root . --current-goal R2
```

路径与 R2 按实际安装及最新确认替换。目标修订不匹配会先把全部动作置为 INSPECT；随后由调用者核对影响，只复做受影响工作。可能已生效的写操作必须先查真实结果；无法查证不重跑，不改签旧回执。Mode 0 不额外保存讨论日志，检查点不保证进程存活或自动续做。

安装与 full/skills-only 差异见[安装入口](install.md)；当前契约见[维护者契约](../maintainers/CODEX-GOAL-BRIDGE.md)。原始研究与未执行场景见[设计基线](../../planning/codex-goal-adaptation-design.md)，其中版本/环境结论只属于当时观测，不能替代本候选验证。
