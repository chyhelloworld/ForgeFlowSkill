# 独立软件图示：ff-diagram

用于创建、修改、审查架构图、数据流图（DFD）、E-R、UML与流程图，不是装饰图片生成，也不替你批准业务架构。可直接调用，无需先跑Spec/Derive或全套FF；只读检查不自动改稿。

例如：“请用 ff-diagram，参考国内软件工程/系统架构设计常用要求，把这份订单方案画成数据流图。说明边界与记法，保留可编辑源；检查父子层平衡，并分别报告语义、渲染和视觉检查结果。未确认业务规则标未知，不自行补定。”

按问题选图，不要求每次全套。默认先确定图的用途/读者、范围、粒度、现状或候选、所选记法，再按图种读本地参考。国标、考试/教材惯例、工程方法不是同一层级；项目明确要求某版教材/模板时按其范围使用。标准未取得正文不声称逐条符合，也不要假设一个国标覆盖所有架构/DFD/E-R/UML，须逐图核适用范围。

应获得：具体对象/关系及主路径可解释，原要求与AI推断可区分；可编辑源和可用导出物；实际检查范围及未验证项。语法通过不是语义正确，截图漂亮不是业务正确；不能渲染或未实际看图时会明确说明，不报视觉通过。无需特定付费绘图平台，安装/外发资料仍按原权限。

当前是未发布源码候选，新增后20技能，历史文档的17/18/19为当时范围。技能发现、安装字节正确、模型执行、用户接受分别验证；静态/合成测试不是对所有未来图质量的保证。
