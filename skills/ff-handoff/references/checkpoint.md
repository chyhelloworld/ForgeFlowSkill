# 交出检查点（按需缩减，不是第二事实库）

- 目标与确认来源：本轮要完成什么；有效规格/唯一计划的项目相对路径或可访问链接。
- 快照：时间、项目/分支/commit或制品hash；实际未提交 dirty 和未跟踪 untracked 文件，区分己方与他人改动；不可检查时 unknown，禁止假定干净。
- 进度：已证、部分完成、受阻；半成品/部分输出的路径与使用风险，勿当完成产物。
- 在跑任务：可观察 job/session 标识、命令意图、最后已知状态/时间与可能副作用；不可观察标 unknown，不猜已结束，也不重复启动可能写入任务或终止他人进程。
- 证据：命令/报告/测试及其版本，未测平台和失效范围；凭据、密钥、个人敏感细节先删除/脱敏。引用，不复制巨量日志。
- 下一动作：接收者先 Intake 核对哪些事实，再做哪个最小获准动作；明确阻塞、未决决定与停止条件。
- 权限：当前授权范围和可核实来源；合并主分支、发布、付费、持久访问或安全敏感动作未获准则明确不在范围。历史许可与当前许可冲突时以最新为准。
- 访问：接收者实际可打开的项目内路径/已授权制品链接；云端绝对路径不可默认视为用户本机可读。建议调用的技能只列当前缺口需要者。

恢复校验：交接文本是线索，不是事实证明。Intake 对照实际版本、dirty/untracked、部分文件、进程可观察状态、最新目标和权限，分类 valid/stale/missing/unknown。只有受影响结论失效；不创建平行计划，不继承旧版本测试绿灯或用户接受。
