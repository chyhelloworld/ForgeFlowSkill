# FF 0.3.1-rc1：Impeccable 设计规则整合

基于 0.3.0-rc4；只更新唯一 ff-design（0.3.1-rc1）及来源、版本、清单文件。其余四个技能的全部内容逐字保留。当前仅云端候选，未安装到 T3，未部署。

## 改变
- SKILL.md：访客模式、复用现有确认的最小 shape、整体设计构思、连续动效及独立 critique。
- references/design-craft.md：可操作工艺、真实触摸/滚轮、暂停/反向/跨段、减少动态效果及无脚本内容可见性。
- 把独立设计检查接到已有主要流程与核心需求、代码规范、计划三类独立审核；不新增第二套记录或替代门禁。
- 批量检查和按缺陷复测以控制成本；缺陷未过/证据未验证不等于通过。
- LICENSE-IMPECCABLE、NOTICE-IMPECCABLE.md、NOTICE.md 与 provenance 保留来源、许可及改动标记。

## 明确不引入
上游运行时、脚本、engine、hooks、live、默认提权、工具输出指令授权、强制重新确认已定目标、固定两轮后通过。用户选定风格优先，审美偏好不变成绝对禁令。

## 验证边界
静态包验证、来源完整性与基线保留检查不等于真实产品体验、真人审美接受、三类独立产品审核或宿主原生安装。博客云端试验另有版本与证据。
