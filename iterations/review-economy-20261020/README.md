## 改动

普通任务改为执行者自检及相关确定性检查，在一份可独立验收的功能切片末，默认一名独立读者复用材料，分别给目标/主流程、计划覆盖、实现质量结论。关键变更先审方案；用户额外要求和既有项目门禁优先。v2 policy/progress 仍可能要求前置计划回执，本候选不改变 CLI 或关闭 reviewRequired。

同步了路由、Intake/Plan/Implement/Review/Deliver、故障修复/TDD 分支、生命周期契约及安装内副本、手册/流程图与能力入口，消除普通任务必前置审核和每次 green 前审核重构的旧冲突。最小证据包保留原始目标、约束、验收、范围/差异、关键测试、已有结论和未验证项；摘要只导航，原文和跨模块影响仍需检查。修复只复核发现和影响链，无关非阻断建议进入待办，新关键缺陷仍阻断。结论沿用 v2 的内容/规则/依赖/输入/证据绑定，不新增技能、缓存、流程框架或生产代码。

## 成本与限制

本轮因变更审查口径先做一次独立方案审核，阶段末一次综合独立审核；F1修复仅局部复核。方案审核自报读取8份不同文件、1次重复定位，36秒；综合审核自报106个不同路径、175次正文/diff/搜索访问，其中重复69次，328秒。这两份计数定义不同，不直接相加。69=175次路径访问−106个不同路径，同文件不同必要片段、diff/原文对照及定位搜索也计入，并非69次相同片段冗余读取。审查者报告编码纠正、截断后定位补读；现有证据没有片段级轨迹或原因频次，不能伪造必要/冗余拆分。没有同任务旧/新流程可比基线，综合328秒与F1复核33秒范围不同，不能据此计算节省。实际token/阅读节省未证明。详见[代理指标](metrics.json)。实际 token/账单与主执行者总上下文统计 unknown，不报告节省比例。接手时一次过宽的工作区检索产生截断输出，随后缩小到 source 和相关原文；不能把本轮当作已经证明总体 token 下降的对照实验。

构造任务可比较审核启动位置和重复材料范围；次数或阅读量只能作代理指标。本轮没有同一真实业务任务的旧/新宿主对照，未验证其他平台。此前 `build.mjs:removeGenerated` 的1函数未测仍为 NOT_MEASURED；继承 archive/validate 的复杂度债务仍在，不改为通过。此次无生产逻辑变更，新增 CRAP 计量 N/A；这不表示全库 CRAP≤50。关键未知仍不能放行，独立无关工作可继续。
