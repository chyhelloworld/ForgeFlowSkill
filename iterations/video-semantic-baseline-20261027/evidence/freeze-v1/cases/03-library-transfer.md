# Case 03 — neighborhood lending library

社区图书室需要一个小型借阅系统。同一书目可能有多册实物，每册有自己的条码；读者按书目排队预约，不预先挑选某册。没有预约队列时，管理员可将可借实物直接借给读者；有队列时，归还的可借实物优先留给排在最前面的有效预约。轮到的读者收到取书通知后有 2 天领取，过期则依次交给下一位；读者也可以主动取消预约。管理员需能区分某册在馆、已借出、为谁待取或损坏不可借。损坏的归还册不能拿来满足预约。

每位读者最多同时借出 3 册，借期 14 天；是否可以新增预约不受当前借出册数影响，但实际领取时仍需满足借出上限。后台工作人员可能在两个窗口操作同一册，不能导致一册同时借给两个人。通知通过现有邮件服务发送；邮件发送失败不能撤销已经记录的归还或借出事实，并允许之后重发通知。现有持久化方式未选定，可提出必要假设。范围不含罚款、支付、推荐或跨馆物流。

请重点说明正常的预约、归还后分配、领取三个用例如何落到可实施设计；同时给出取消、过期和损坏在设计中的位置。
