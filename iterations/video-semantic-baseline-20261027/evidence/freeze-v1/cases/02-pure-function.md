# Case 02 — small calculation

需要给现有 TypeScript 项目增加一项金额计算能力。输入是非负安全整数的商品单价（分）、非负整数数量、0 到 100 的整数折扣百分数。输出折后总价（分）；先计算单价乘数量，再乘（100 − 折扣百分数）/100，最后四舍五入到整数分，0.5 向上。任一输入不符合范围，或折扣前总价超出安全整数范围时，返回可区分的输入错误，不返回部分金额。不需要数据库、网络、存储、配置系统或运行中的任务。

业务样例：单价 199 分、数量 3、折扣 10%，结果为 537 分；单价 1 分、数量 1、折扣 50%，结果为 1 分；数量 0 时结果为 0 分。非法折扣与总价溢出需要能被调用方区分。已有项目只需能导入该能力并测试它。
