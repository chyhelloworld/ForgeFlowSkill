## Exact sequence

1. Verify FREEZE.sha256 and original baseline manifest before launching. Parent records actual executor model/version and exposed settings, invocation timestamp, assigned skill snapshot path/hash, tool allowlist and isolated output path. If model metadata is unavailable, say so; never fabricate it.
2. Fresh blind executor runs OLD once on Case 01. Retain full FIRST response, tool trace and artifacts, including unsuccessful results; do not select retries.
3. Fresh independent evaluator receives anonymous output, the same requirement/handoff and evaluator-only reference/rubric. Retain judgment before any correction. True behavioral red requires a requirement-grounded material defect, not preferred names, layer count, length, environment failure or a missing optional feature.
4. If old is adequate, report no reproduced defect and do not manufacture red or patch anyway. If inconclusive, resolve evidence without relabeling it red; any added matched sampling must be separately declared and preserve the first run.
5. Only after baseline output AND independent red judgment are frozen may parent authorize the smallest correction in a separate cloud candidate copy. No unrelated refactor.
6. Fresh blind executor runs the same frozen primary input on the candidate with matching model/settings where available. Fresh independent evaluator applies the same criteria. Preserve first output. Incomplete execution is not green. A remaining defect stays in this single loop.
7. Once this primary behavior is green, run frozen simple-function and library cases as necessary affected regressions. To substantiate no regression, compare old and candidate under the same control input/handoff and available execution settings, preserving first outputs and independent evaluations. Do not initiate these controls before primary green. A regression is addressed within its own observed behavior loop, not by batch speculative edits.
8. Review/prove are performed only as the skill or demonstrated uncertainty requires; do not automatically run all three cases through separate derive-review-prove stages. No second primary behavior is selected before closing the current loop.

## Evidence and limits

It must not be reported as fully automated TDD or universal proof of architectural quality. File/hash/link/diagram-reference checks are mechanical supporting evidence only. One first sample per treatment is diagnostic, not a reliability estimate. Preserve NOT_RUN/INCONCLUSIVE and do not infer safety/performance from design prose.
