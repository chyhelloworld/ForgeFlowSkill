# RSI 契约核实与修复

用户在六项执行规范增量之后授权：核实独立评估，正确的问题一起优化。基于同一 0.10.0 工作分支，不合并、不发布、不升级真实安装。

## 实际复现与修复

新增四项 Node CLI 回归在原实现上全部失败，原有 16 项通过；修后 20/20 通过：

- promote 原来仅拒 L0，缺失/非法 independence 也能写晋级记录；现在只接受既有 L1/L2 契约。
- freeze 重复 --fail 覆盖前值；现在 --fail/--normal 全部保留，继续拒绝重复 case id。
- compare 后行 NO_EFFECT 能覆盖先前 REJECTED；现在按 REJECTED > NO_EFFECT > PASS 汇总。原问题不会把失败变 PASS，但会丢失拒绝归因。
- promote 未校验文档要求的 unverified；现在要求数组，可显式为空。不扩展数组元素格式约束，也不声称能证明审查独立性或未验证内容真实性。

`docs/user/rsi.md` 同步上述原契约。`docs/user/install.md` 的当前口径改为 0.10.0 / 21 技能 / CLI 从源码版本派生；旧 0.9.x 数量和原生证据分组保留为历史，不据此宣称当前原生验收。

原始红/绿日志保存在本轮外部检查目录，测试文件在仓库可复跑。本轮未修改安装机制、门禁权限或主分支；无 Windows/真实宿主/业务项目验收。
