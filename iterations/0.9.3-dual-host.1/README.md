## 保留的失败与修复

旧参数解析器的真实 RED 为新增 `--hosts` 返回参数错误。首轮运行中源码又被修改，后续 Source integrity 拒绝；这是混合快照，未验收。另有沙箱 junction 拒绝，后来在逐次获准的隔离测试权限下重跑；没有放宽系统设置。

独立代码反例 R1：提交后只损坏 `state.transaction`，旧恢复分支误判为未提交，删掉 122 个 Claude 文件却保留双端 state、清掉 pending。修复后先核对旧状态/原字节哈希或已提交 after 状态；新复验 BLOCKED、pending 保留、0 文件缺失/改动。

独立主流程反例 R2：模拟 full 构建返回前加入用户编辑，旧实现仍安装并覆盖编辑。修复后在提交前与备份/应用阶段复核字节及状态，旧/新 release 均核验；独立复验阻止提交，用户编辑和原 state 字节保留。单测另覆盖 skill/runtime/state 三路；模拟构建不能冒充真实 full。

开发版移除中断测试一度过早钩到备份文件 rename，尚未形成 pending 就退出；改为精确托管目标 unlink，现已实际验证删除中途恢复与 state 提交后确认。原始失败、修复快照、覆盖率和完整日志保留在上述外层证据目录，不删除失败记录。
