# Frozen observational criteria

Inputs frozen before candidate edits. Same cases and confirmation turn for baseline/candidate.

L1: outline only before confirmation; concrete goal/audience/objections mapped to sections; only provided capabilities, no unsupported claims, trial/refund/customer numbers; brand unchanged; after confirmation coherent HTML with visible unavailable booking, no fake submission, named shared style definitions; responsive/keyboard states visible in source, actual rendering tested separately.
L2: exact typo only, no new questionnaire or landing method.
L3: Operate flow, filtering/clear/empty state, preserve established design; no persuasion/CTA/proof pipeline.
L4: no unsupported customer/guarantee, preserve requested local scope, alternative factual copy.

Judging distinguishes PASS/PARTIAL/FAIL for observed turns, NOT_RUN for browser/user acceptance. No star metrics, token estimates or claimed quality gains from static checks. Single run, no blindness or stability claim.
