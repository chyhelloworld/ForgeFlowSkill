# 五个可选方法：单次受指示行为模拟

## 结论

本次完成了一个明确标为 SYNTHETIC 的中文短博客写作模拟。初始错误能力说法和无来源效率数字被拦下，作者修改被保留；shape 完成短稿，beats 作为独立替代路线在一个节拍后停止；retro 证伪了重复规则候选，新增规则 0、补丁 0。

这是同一模型按明确场景自构作者 fixture 并逐步执行的一次模拟。不是盲测，不是独立评审，不提供成功率，也不证明 CLI 能执行语义规则或识别真实批准。作者 fixture 的“选择”“完成”始终不是现实用户批准。

## 交付

- [短博客成稿](shape-draft.md)：两个经 fixture 选择的写作块；保留“第一次接手项目”的作者修改。后来按测试协调者指出的精确性问题，另做一次明确标记的模拟后文字修正。没有假效率指标、假引用或“自动成文”主张。
- [素材](fragments.md)：模型只创建一次并追加，作者自行删改；stop 后没有追加或继续采访。
- [Beats 替代分支](beats-draft.md)：只写一个选中节拍，作者删除“哈希/指纹”后，重读并重建下一轮两个候选；没有预写下一节拍。按 fixture 停止，故有意保持未完成。
- [研究](research.md)：事实、推论和待实测分开；引用 [提取的执行证据](evidence-extract.json) 及小型来源快照。
- [复盘](retro.md)：展示候选后，用现行核验要求反证“缺规则”；零新增规则、零补丁。
- [逐轮可读记录](TRANSCRIPT.md)、完整机器可读输入输出 transcript.jsonl、每次文件写入 snapshots/、输入快照 inputs/。
- [机械核对结果](verification.json) 与 verify_simulation.py：14/14 记录完整性检查成立；这不是 14 个独立行为实验。

## 关键可复核位置

transcript.jsonl 事件编号：
- 12–19：合成错误输入、冲突说明、原始素材留档。
- 25–33：作者删除数字并改变受众；模型完整重读后只追加，保留编辑。
- 35–36：作者 stop，素材收集结束。
- 43–54：beats 三个起点、选择一个、只写一个；删除概念后重建候选并停止。
- 61–74：shape 三个开头、选中 A、仅落开头；第二次选择 D 才追加检查点，保留作者修改，作者宣布本地完成。
- 76–82：retro 候选先展示、重读已有规则、证伪并输出零规则。
- 88–94：后续精确性审阅指出测试 5 节点与交付 4 节点的区别；读取交付 schema 后修正博客措辞，原模拟快照仍保留。该修正没有伪装成合成作者的新选择。

## 证据与限制

本模拟冻结的是原 39 条 commands.json 执行记录。没有把脚本后来新增但该快照尚未执行的 semantic non-enforcement 用例冒充为已跑结果。原命令和检查记录已按 json_pointer 提取，导出不必重复带两个大原日志。

原自构测试的两条依赖链各 5 节点，含额外 retro；实际交付 blog schema 各 4 节点，不强制 retro。成稿已使用“本次配置了依赖的材料”这一限定说法。有效哈希和合成 review 收据只支持绑定匹配，不认证批准者身份。

已观察到一个小的可读性不足：shape 成稿使用 ffValidity/done 标签时没有充分展开字段含义，对首次维护者仍可更清楚。本次如实保留并报告，不把机械检查通过写成全部写作质量都通过。
