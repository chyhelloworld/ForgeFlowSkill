# 扫码产品追溯建设方案

## 1. 建设目标与本期范围

本期建设的目标是：生产人员录入标签并关联产品信息后，消费者能够通过手机扫码查看对应的产品档案。

“产品档案”指系统中记录的产品信息；标签用于建立产品与档案之间的对应关系。本期实现档案管理和查询，不将扫码查询等同于防伪鉴定或完整生产过程追踪。

本期包含：
- 后台产品档案管理。
- 生产人员通过电脑连接读卡器录入标签，并关联对应产品。
- 消费者通过手机扫码公开查询产品档案。

本期不包含付款功能。

## 2. 谁使用什么

下图回答“谁通过什么入口完成什么事情”：

```text
生产人员
   │ 使用电脑连接读卡器
   ▼
录入标签 → 关联产品 → 在后台管理产品档案
                            │
                            │ 提供可公开查询的产品信息
                            ▼
消费者 → 使用手机扫码 → 查看对应产品档案
```

生产人员的读卡器录入与消费者的手机扫码是两个不同入口。图示表达拟建使用方式，不代表设备兼容已经验证。两类入口均须完成兼容测试，见第4章。

## 3. 本期功能与使用流程

### 3.1 后台档案管理

生产人员在电脑端使用后台，录入并维护产品档案，将读取的标签信息与对应产品关联，使消费者扫码时能够找到对应档案。

具体档案字段、允许公开展示的信息，以及后台操作权限，需在实施前确认；不默认将全部后台信息公开。

### 3.2 生产人员使用流程

1. 使用电脑连接拟选读卡器。
2. 通过读卡器读取并录入标签信息。
3. 将标签与对应产品关联，并维护产品档案。
4. 核对标签与产品的对应关系及可公开查询的信息。

该流程的预期结果是建立正确的“标签—产品—档案”对应关系。具体标签如何与消费者手机扫码入口对应，尚需结合拟选标签与设备验证，不能仅凭读卡器可读取就认定手机可查询。

### 3.3 消费者使用流程

1. 使用手机扫描产品上的查询标识。
2. 进入对应产品的公开查询页面。
3. 查看允许公开展示的产品档案。

此流程不包含付款。标签未关联、信息缺失或无法识别等异常情况下的页面提示，需要在功能细化时确认。

## 4. 使用条件与待验证事项

目前尚未完成读卡器和客户手机的兼容测试，不能承诺所有读卡器、电脑或手机均可使用。

实施前需用拟选标签及设备进行实际验证：
- **生产端**：验证电脑与读卡器能否正常连接、读取标签并完成录入与关联。
- **消费端**：用客户拟支持的手机验证扫码、打开查询页面及显示档案的完整流程。
- **对应关系**：验证消费者扫描的标识能够定位到生产端关联的正确产品档案。
